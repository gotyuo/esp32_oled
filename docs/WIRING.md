# 硬件连接图 (WIRING.md)

版本: v2.0.0
适用平台: ESP32 / ESP8266

本文档用 ASCII 图说明各传感器的接线方式。所有传感器供电电压均为 **3.3V**，切勿使用 5V。

---

## 1. ESP32 连接图

### 1.1 总览

```
                        ┌─────────────────────────────┐
                        │          ESP32 Dev Board     │
                        │                              │
   [DHT22]              │  VCC ──────── 3.3V           │
    │                   │                              │
    └── GPIO 4 (D)      │  GND ──────── GND            │
                        │                              │
   [BMP280]             │                              │
    │  │                │                              │
    └──┴── I2C          │  GPIO 21 ──── SDA (I2C) ─┐  │
    SDA/SCL ────────────│  GPIO 22 ──── SCL (I2C) ─┤  │
                        │                              │
   [OLED SSD1306]       │                              │
    SDA/SCL ────────────│  GPIO 21 ──── SDA (I2C) ─┤  │
                        │  GPIO 22 ──── SCL (I2C) ─┘  │
                        │  GPIO 4  ──── DHT22 DATA     │
                        │  GPIO 34 ──── I2S CLK        │
                        │  GPIO 32 ──── I2S DOUT (MIC) │
                        │  GPIO 25 ──── I2S BCLK/DAC0  │
                        │  GPIO 26 ──── I2S DAC1       │
                        │  GPIO 34 ──── ECG (reserved) │
                        │  GPIO 35 ──── ECG (reserved) │
                        │                              │
                        └─────────────────────────────┘
                                     │
                                     │ 3.3V / GND
                                     ▼
                            [传感器共享电源]
```

### 1.2 OLED 显示 (SSD1306)

```
[SSD1306 I2C OLED Module]      [ESP32]
        VCC ─────────────── 3.3V
        GND ─────────────── GND
        SDA ─────────────── GPIO 21
        SCL ─────────────── GPIO 22
        INT ─ (可选, 不用中断可悬空)

上拉:  SDA/SCL 各接 4.7kΩ 到 3.3V (模块板通常已内置)
```

### 1.3 DHT22 温湿度传感器

```
[DHT22 Module]                 [ESP32]
   VCC ───────────────── 3.3V
   GND ───────────────── GND
   DATA ──────────────── GPIO 4

上拉:  DATA 接 4.7kΩ 到 3.3V (模块板通常已内置)
```

### 1.4 BMP280 气压传感器 (I2C, 与 OLED 共享总线)

```
[BMP280 Module]                [ESP32]
   VCC ───────────────── 3.3V
   GND ───────────────── GND
   SDA ──────────────── GPIO 21  (与 OLED 共用)
   SCL ──────────────── GPIO 22  (与 OLED 共用)
   ALERT ─ (可选)
```

### 1.5 麦克风 (I2S, 如 INMP441 / MSM261S)

```
[INMP441 MEMS Mic]             [ESP32]
   VCC ───────────────── 3.3V
   GND ───────────────── GND
   SD  ──────────────── GPIO 32  (I2S DOUT)
   SCLK ─────────────── GPIO 34  (I2S CLK, 模拟通道)
   LRCLK ─────────────── GPIO 25  (I2S BCLK / WS)
   L/R ─ (单声道时接 GND)
```

> ⚠️ GPIO 34 与心电监护复用，运行时二选一。

### 1.6 喇叭 (I2S DAC, GPIO 25/26)

```
[喇叭 + 功放板]                 [ESP32]
   VCC ───────────────── 5V   (功放模块)
   GND ───────────────── GND
   IN+ ──────────────── GPIO 25  (DAC0)
   IN- ─ (建议接 GND, 单声道)
   或 IN- ────────────── GPIO 26  (DAC1, 立体声)
```

> ⚠️ 多数功放模块 (如 PAM8403) 自带 5V 供电。ESP32 仅驱动信号线，不驱动喇叭功率。

### 1.7 心电监护 (AD8232, 预留)

```
[AD8232 ECG Module]            [ESP32]
   VCC ───────────────── 3.3V 或 5V (按模块规格)
   GND ───────────────── GND
   OUT ──────────────── GPIO 34  (与麦克风 CLK 复用, 运行时二选一)
   REF+ ─ (按 AD8232 数据手册)
   REF- ─ (按 AD8232 数据手册)
   HL ─ (心率检测引脚, 可选)
   HR ─ (输出心率, 可选)
   LD ─ (低电平检测, 可选)
   LEAD1/2/3 ── 心电线

外部上拉: GPIO 34 接 10kΩ 到 3.3V (ADC1 无内部上拉)
```

> 心电监护功能当前为占位实现 (`ekg_stub.cpp`)，接线已预留但代码未启用。

```
   SDA/SCL        │                          │
                  └──────────────────────────┘
```

### 2.2 OLED 显示 (SSD1306)

```
[SSD1306 I2C OLED]             [ESP8266]
   VCC ───────────────── 3.3V
   GND ───────────────── GND
   SDA ──────────────── GPIO 4
   SCL ──────────────── GPIO 5
```

### 2.3 DHT11 温湿度传感器

```
[DHT11 Module]                 [ESP8266]
   VCC ───────────────── 3.3V
   GND ───────────────── GND
   DATA ──────────────── GPIO 3

上拉:  DATA 接 4.7kΩ 到 3.3V (模块板通常已内置)
```

### 2.4 ESP8266 不支持的外设

| 外设 | 状态 | 原因 |
|------|------|------|
| BMP280 气压 | ❌ | 引脚不足 (可复用 OLED I2C, 但当前固件未实现) |
| 麦克风 | ❌ | ESP8266 无 I2S 外设 |
| 喇叭 | ✅ | 有源蜂鸣器 / 喇叭模块，GPIO 驱动 |
| 心电监护 | ❌ | 无模拟输入引脚 (ESP8266 无 ADC) |

## 3. 传感器接线说明

### 3.1 电源树

```
[USB 5V 输入]
    │
    ├── ESP32/ESP8266 板载 3.3V 稳压 ──→ 3.3V (供电 OLED, DHT, BMP)
    │
    └── 5V 直接输出 ──→ 功放模块 (PAM8403 等)
                        │
                        └── 喇叭 (8Ω 0.5W 或更大)
```

### 3.2 I2C 多设备共享

ESP32 上 OLED 与 BMP280 共享 I2C 总线：

- 两个模块通过不同的 I2C 地址区分 (SSD1306: 0x3C, BMP280: 0x76)
- I2C 频率 100 kHz 即可
- 上拉电阻接在总线上，所有从设备共用

### 3.3 麦克风 / 喇叭接线细节

- 麦克风供电必须 3.3V (INMP441 模块板内置 3.3V LDO)
- 喇叭不直接接 ESP32 GPIO (会烧芯片)，必须经功放板
- 功放板输出可承受 5V / 3W，与 ESP32 信号线分离

### 3.4 心电监护预留接线

- AD8232 模块的 OUT 引脚通过 10kΩ 电阻接 ESP32 GPIO 34
- 必须接地参考 (REF+ / REF- 按 AD8232 数据手册)
- 心电线需阻抗匹配 (1 MΩ) 与滤波 (50Hz 陷波)

## 4. 安全与排错

### 4.1 通用注意事项

- ⚠️ **3.3V 而非 5V**: 所有传感器供电必须 3.3V
- ⚠️ **先接线后上电**: 避免短路损坏
- ⚠️ **接地共地**: 所有模块 GND 必须连到同一参考点
- ⚠️ **避免占启动引脚**: 见 PINS.md §4.4

### 4.2 常见接线错误

| 现象 | 可能原因 | 解决 |
|------|----------|------|
| OLED 无显示 | I2C 地址错 / 上拉缺失 | 用 I2C Scanner 扫描 |
| DHT 读取失败 | 上拉电阻缺失 / 引脚错 | 检查 4.7kΩ 上拉 |
| 麦克风无声 | 引脚复用冲突 | 检查 GPIO 25 是否被喇叭占用 |
| 喇叭杂音 | 电源纹波 | 功放电源加 100μF 电容 |
| 设备无法启动 | 占用 boot 引脚 | 见 PINS.md §4.4 |

### 4.3 I2C 扫描工具

```cpp
// 上传后打开串口监视器 (115200)
#include <Wire.h>
void setup() {
  Wire.begin(21, 22);  // ESP32: SDA=21, SCL=22
  Serial.begin(115200);
  Serial.println("Scanning I2C...");
  byte n = 0;
  for (byte i = 1; i < 127; i++) {
    Wire.beginTransmission(i);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Found: 0x%02X\n", i);
      n++;
    }
  }
  Serial.printf("Found %d device(s)\n", n);
}
void loop() {}
```

预期输出:
```
Found: 0x3C   (OLED SSD1306)
Found: 0x76   (BMP280)
```
