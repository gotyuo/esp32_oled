# 引脚分配文档 (PINS.md)

版本: v2.0.0
适用平台: ESP32 / ESP8266

本文档列出 EnvMon 固件在所有引脚上的连接定义。所有引脚映射在固件配置头文件 (`envmon_*.h`) 中集中定义，修改硬件连接后必须同步更新此处与配置头文件。

---

## 1. ESP32 引脚表

### 1.1 完整引脚分配

| 外设 | 接口 | GPIO | 方向 | 备注 |
|------|------|------|------|------|
| OLED 显示 (SSD1306) | I2C SDA | **GPIO 21** | I/O | 内部上拉 |
| OLED 显示 (SSD1306) | I2C SCL | **GPIO 22** | I/O | 内部上拉 |
| DHT22 温湿度 | 单总线 | **GPIO 4** | I/O | 内部上拉，需 4.7kΩ 上拉电阻 |
| BMP280 气压 | I2C (共享总线) | SDA=21 / SCL=22 | I/O | 与 OLED 共用 I2C 总线 |
| 麦克风 (I2S) | I2S CLK | **GPIO 34** | 输入 (ADC1) | 模拟通道，仅能作输入 |
| 麦克风 (I2S) | I2S DOUT | **GPIO 32** | 输入 (ADC1) | 模拟通道，仅能作输入 |
| 麦克风 (I2S) | I2S BCLK/WS | **GPIO 25** | 输出 | 与喇叭 DAC 复用，需软件分时 |
| 喇叭 (I2S DAC) | I2S DAC | **GPIO 25** | 输出 | 复用 DOUT/DAC |
| 喇叭 (I2S DAC) | I2S DOUT | **GPIO 26** | 输出 | DAC1 |
| 心电监护 (AD8232) | ADC1 | **GPIO 34** | 输入 (ADC1) | 预留，与麦克风共用，运行时二选一 |
| 心电监护 (AD8232) | ADC1 | **GPIO 35** | 输入 (ADC1) | 预留，仅能作输入 |

> **注意**: GPIO 34/35 仅能作为输入 (无内部上拉)，且属于 ADC1 通道。在 ESP32 上，当 WiFi 使用 ADC1 校准通道时，这些引脚的 ADC 精度会受影响。

### 1.2 I2C 总线拓扑

ESP32 上 OLED 与 BMP280 共享 I2C 总线：

```
         VCC (3.3V)
          |
    +-----+-----+
    |     |     |
   [OLED] [BMP280]
    |     |     |
    SDA---+---SDA
    SCL---+---SCL
    |     |
    GND   GND
```

- I2C 频率: 100 kHz (SDA=GPIO 21, SCL=GPIO 22)
- 必须加 4.7kΩ 上拉电阻到 3.3V (部分模块板已内置)

## 2. ESP8266 引脚表

### 2.1 完整引脚分配

| 外设 | 接口 | GPIO | 方向 | 备注 |
|------|------|------|------|------|
| OLED 显示 (SSD1306) | I2C SDA | **GPIO 4** | I/O | 内部上拉 |
| OLED 显示 (SSD1306) | I2C SCL | **GPIO 5** | I/O | 内部上拉 |
| DHT11 温湿度 | 单总线 | **GPIO 3** | I/O | 内部上拉 |

> **注意**: ESP8266 引脚数量少 (仅 GPIO 0-16)，且 GPIO 0/2/15 在启动时特殊用途 (boot mode)。请勿将传感器连接到 GPIO 0 (boot) 或 GPIO 15 (boot 相关)。

### 2.2 ESP8266 引脚可用性速查

| GPIO | 可用性 | 说明 |
|------|--------|------|
| 0 | ⚠️ 谨慎 | 启动时下拉触发 Flash 模式，建议避免用作 I/O |
| 1 | 可用 | 串口输出 (启动时)，运行时可作 GPIO |
| 2 | ⚠️ 谨慎 | 启动时下拉触发 SPI 模式 |
| 3 | ✅ | 推荐用作传感器输入 |
| 4 | ✅ | 推荐用作 I2C SDA |
| 5 | ✅ | 推荐用作 I2C SCL |
| 15 | ⚠️ 谨慎 | 启动时下拉会卡启动 |
| 16 | ⚠️ | 不可用作中断输入 (仅可作输出/普通读取) |

## 3. ESP32 vs ESP8266 对比表

| 特性 | ESP32 | ESP8266 |
|------|-------|---------|
| OLED (SSD1306) I2C | SDA=**21**, SCL=**22** | SDA=**4**, SCL=**5** |
| 温湿度传感器 | DHT22 @ **GPIO 4** | DHT11 @ **GPIO 3** |
| 气压传感器 (BMP280) | ✅ I2C (21/22) | ❌ 不支持 |
| 麦克风 (I2S) | ✅ GPIO 34/32/25 | ❌ 不支持 |
| 喇叭 (I2S DAC) | ✅ GPIO 25/26 | ❌ 不支持 |
| 心电监护 (预留) | ✅ GPIO 34/35 | ❌ 不支持 |
| OTA | ✅ | ✅ |
| Flash 大小 | 2-16 MB | 1-4 MB |
| SRAM | 520 KB | 80 KB |

## 4. 注意事项

### 4.1 电源

- 所有传感器供电电压：**3.3V** (切勿使用 5V)
- 5V 模块需外接电平转换 (ESP32/8266 GPIO 均为 3.3V 容忍)
- DHT22 工作电流约 1.5 mA，BMP280 约 30 μA，无电源瓶颈

### 4.2 引脚复用冲突

- **ESP32 GPIO 25**: 同时用于 I2S BCLK (麦克风) 和 I2S DAC (喇叭)。运行时通过软件分时复用，不能同时进行麦克风采集与喇叭输出。
- **ESP32 GPIO 34**: 同时用于 I2S CLK (麦克风) 和 AD8232 心电采集 (预留)。运行时二选一。
- 若需同时使用麦克风与喇叭，建议重新分配引脚：麦克风 GPIO 34/32/33，喇叭 GPIO 25/26。

### 4.3 模拟引脚限制

- ESP32 的 ADC 仅支持 GPIO 32-39 (其中 36/39 无内部上拉)
- GPIO 34/35 属 ADC1 通道，**仅输入**，无内部上拉电阻
- 若需要上拉，请外接 4.7kΩ 电阻到 3.3V

### 4.4 启动引脚 (切勿占用)

- ESP32 GPIO 0: 下拉进入下载模式
- ESP32 GPIO 2: 启动 LED (默认拉低)
- ESP32 GPIO 12: 下拉会禁用 Flash 模式
- ESP32 GPIO 15: 下拉进入下载模式
- ESP8266 GPIO 0/2/15: 同上 (boot mode)

### 4.5 修改引脚分配

1. 同步修改 `esp32/envmon_esp32.h` 或 `esp8266/envmon_esp8266.h` 中的 `#define PIN_*`
2. 同步更新 `docs/WIRING.md` 中的连接图
3. 重新编译并烧录
