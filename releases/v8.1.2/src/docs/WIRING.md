# 硬件连接图 (WIRING.md)

版本: **v8.1.2** (2026-10-06)
适用平台: ESP32-S3-N16R8
硬件方案: SSD1306 OLED (I2C) + DHT22 + BMP280 + MAX98357A I2S DAC

> 接线时看 **丝印 D# 标号**（板子上只印 D#，不印 GPIO 编号）。
> 所有传感器供电电压均为 **3.3V**，切勿使用 5V。

---

## 1. 总览

```
                  ┌─────────────────────────────┐
                  │        ESP32-S3 Dev Board    │
                  │                             │
   [OLED SSD1306] │  3V3 ─────────── VCC        │
     SDA ────────│  D8  ─────────── I2C SDA     │
     SCL ────────│  D9  ─────────── I2C SCL     │
                  │                             │
   [BMP280]       │  (与 OLED 共用 I2C 总线)     │
     SDA ────────│  D8                        │
     SCL ────────│  D9                        │
                  │                             │
   [DHT22]        │  D4  ─────────── DHT DATA   │
     DATA ───────│                             │
                  │                             │
   [MAX98357A]    │  D38 ─────────── I2S SDOUT  │
     SDOUT ──────│  D18 ─────────── I2S BCLK   │
     BCLK ───────│  D39 ─────────── I2S LRC    │
                  │                             │
   [LED]          │  D2  ─────────── LED        │
                  │                             │
                  │  3V3 ─────────── VCC        │
                  │  GND ─────────── GND        │
                  └─────────────────────────────┘
```

## 2. OLED 显示 (SSD1306, 128x64)

```
[SSD1306 I2C OLED Module]        [ESP32-S3]
        VCC ─────────────── 3V3
        GND ─────────────── GND
        SDA ─────────────── D8   (GPIO 8)
        SCL ─────────────── D9   (GPIO 9)
        RST ─ (未接线, 库自动管理)
```

**注意**:
- ⚠️ **VCC 必须接 3.3V，接 5V 会烧毁屏**
- 上拉: SDA/SCL 各接 4.7kΩ 到 3.3V（模块板通常已内置）
- OLED 地址 0x3C，库会自动探测 0x3C / 0x3D

---

## 3. DHT22 温湿度传感器

```
[DHT22 Module]                   [ESP32-S3]
   VCC ───────────────── 3V3
   GND ───────────────── GND
   DATA ──────────────── D4    (GPIO 4)
```

**注意**:
- 上拉: DATA 接 4.7kΩ 到 3.3V（模块板通常已内置）
- ⚠️ 如果 DHT22 持续读失败，检查：
  1. 接线是否松动（DATA 和 VCC 最容易松）
  2. 供电是否稳定（3.3V 不能低于 3.0V）
  3. 模块是否损坏（换模块测试）

---

## 4. BMP280 气压传感器 (I2C, 与 OLED 共享总线)

```
[BMP280 Module]                  [ESP32-S3]
   VCC ───────────────── 3V3
   GND ───────────────── GND
   SDA ──────────────── D8      (与 OLED 共用)
   SCL ──────────────── D9      (与 OLED 共用)
   ALERT ─ (可选, 悬空)
```

**注意**:
- 地址 0x77
- 与 OLED 共用 I2C 总线，不需要额外接线

---

## 5. 喇叭 (MAX98357A, I2S DAC)

```
[MAX98357A Module]               [ESP32-S3]
   VCC ───────────────── 3V3
   GND ───────────────── GND
   SDOUT ─────────────── D38     (GPIO 38)   ← 数字音频数据
   BCLK ──────────────── D18     (GPIO 18)   ← 位时钟
   LRC ───────────────── D39     (GPIO 39)   ← 帧同步
```

**注意**:
- MAX98357A 内置功率放大器，可直接驱动小喇叭
- 三脚独立，不与麦克风复用
- 采样率 16000 Hz, 16-bit, mono

---

## 6. 板载 LED

```
[LED]                            [ESP32-S3]
   GND ───────────────── GND
   LED ──────────────── D2      (GPIO 2)
```

## 8. 快速检查清单

烧录前确认：

- [ ] OLED VCC 接 **3.3V**（不是 5V！）
- [ ] OLED SDA = D8, SCL = D9
- [ ] DHT22 DATA = D4
- [ ] BMP280 SDA/SCL 与 OLED 共用 (D8/D9)
- [ ] 喇叭 SDOUT = D38, BCLK = D18, LRC = D39
- [ ] 所有传感器 GND 连在一起
- [ ] 供电 3.3V 稳定（不低于 3.0V）

---

## 9. 常见问题

### Q: OLED 屏幕不亮？
1. 检查 VCC 是否接 3.3V（接 5V 会烧屏）
2. 检查 SDA/SCL 是否接 D8/D9
3. 运行 I2C 扫描确认能找到 0x3C 地址
4. 检查固件版本是否为 v8.1.0+（旧版 WiFi 阻塞导致黑屏）

### Q: 温度湿度读不到 (DHT22 read failed)？
1. 检查 DATA 线是否松动（D4）
2. 检查供电是否稳定
3. 尝试更换 DHT22 模块
4. 这不是固件问题，是硬件接线或模块问题

### Q: 喇叭没声音？
1. 检查 SDOUT/BCLK/LRC 是否接 D38/D18/D39
2. 检查 MAX98357A 供电
3. 固件版本需为 v8.1.0+（旧版喇叭初始化被 WiFi 阻塞）

### Q: WiFi 连不上？
1. 确认固件版本为 v8.1.1+（v8.1.0 及之前 WiFi 密码写错）
2. 确认路由器 SSID 和密码正确
3. 确认设备在路由器信号范围内
