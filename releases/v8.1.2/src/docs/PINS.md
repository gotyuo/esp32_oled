# 引脚分配文档 (PINS.md)

版本: **v8.1.2** (2026-10-06)
适用平台: ESP32-S3-N16R8
硬件方案: SSD1306 OLED (I2C) + DHT22 + BMP280 + MAX98357A I2S DAC

> 引脚标注同时给出 **GPIO 编号**和**丝印 D# 标号**。
> 板子上只印 D#，不印 GPIO 编号。接线时看丝印 D#。

## 2. I2C 总线拓扑

OLED 与 BMP280 共享 I2C 总线 (SDA=D8, SCL=D9)：

```
         VCC (3.3V)
          |
    +-----+-----+
    |     |     |
   [OLED] [BMP280]
    |     |     |
   SDA----+----SDA   ── GPIO 8  (D8)
   SCL----+----SCL   ── GPIO 9  (D9)
    |     |     |
   GND   GND   GND
```

- I2C 频率: 100 kHz (默认)
- OLED 地址: 0x3C (库自动探测 0x3C / 0x3D)
- BMP280 地址: **0x77**
- 上拉: SDA/SCL 各接 4.7kΩ 到 3.3V (模块板通常已内置)

---

## 3. I2S 喇叭拓扑

MAX98357A 是 I2S 数字转模拟 DAC，三脚独立：

```
                 [MAX98357A]
                    |
        VCC ─────── 3.3V
        GND ─────── GND
                    |
        SDOUT ─── GPIO 38  (D38)   ← 数字音频数据
        BCLK  ─── GPIO 18  (D18)   ← 位时钟
        LRC   ─── GPIO 39  (D39)   ← 帧同步 (字时钟)
```

- 采样率: 16000 Hz, 16-bit, mono
- I2S 端口: I2S_NUM_1 (不使用 I2S_NUM_0)
- 喇叭引脚与麦克风引脚**不复用**，可独立工作

## 4. 引脚复用冲突检查

| GPIO | 用途 | 冲突? |
|------|------|-------|
| 8 (D8) | OLED SDA + BMP280 SDA | ✅ 共享 I2C 总线，正常 |
| 9 (D9) | OLED SCL + BMP280 SCL | ✅ 共享 I2C 总线，正常 |
| 4 (D4) | DHT22 | ✅ 独占 |
| 18 (D18) | I2S BCLK | ✅ 独占 |
| 38 (D38) | I2S SDOUT | ✅ 独占 |
| 39 (D39) | I2S LRC | ✅ 独占 |
| 2 (D2) | LED | ✅ 独占 |

**无引脚复用冲突。**

## 5. 电源

| 器件 | 供电电压 | 备注 |
|------|----------|------|
| OLED (SSD1306) | **3.3V** | ⚠️ 切勿用 5V，会烧屏 |
| DHT22 | **3.3V** | 工作电流约 1.5 mA |
| BMP280 | **3.3V** | 工作电流约 30 μA |
| MAX98357A | **3.3V** | 内置 PA，可直接驱动小喇叭 |

ESP32-S3 GPIO 均为 **3.3V 容忍**，切勿直接接 5V。

---

## 6. 启动引脚 (ESP32-S3, 切勿占用)

| GPIO | 说明 |
|------|------|
| 0 | 下拉进入下载模式 |
| 45/46 | Flash 数据引脚 (内部) |
| 35/37 | VDD_SPI (内部) |

当前固件使用的引脚 (2/4/8/9/18/38/39) **均不涉及启动引脚**。

---

## 7. 修改引脚分配

1. 修改 `esp32/envmon_esp32.h` 中对应的 `#define` (如 `OLED_SDA_PIN`)
2. 同步修改 `platformio.ini` 的 `build_flags` 中 `-DPIN_*` 定义
3. 同步更新本文档 (`docs/PINS.md`) 和 `docs/WIRING.md`
4. 重新编译并烧录
